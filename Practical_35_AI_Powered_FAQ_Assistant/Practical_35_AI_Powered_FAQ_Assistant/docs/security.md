# Security Considerations

1. Use only verified, approved FAQ content.
2. Do not include passwords, API keys, student IDs, personal phone numbers, grades, or confidential records in the public repository.
3. If an external AI API is added later, store its key in an environment variable or secret manager; never commit it to GitHub.
4. Share only information approved for public/student access.
5. Do not treat an AI answer as an official policy decision. Verify policy-sensitive questions with the institute office.
6. Keep sample data fictional or generic.
7. Review changes to FAQ answers before publishing.
