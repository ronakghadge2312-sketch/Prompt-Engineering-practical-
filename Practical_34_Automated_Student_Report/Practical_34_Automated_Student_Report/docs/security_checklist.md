# Security and Privacy Checklist

- [ ] Use fictional data in public GitHub repositories.
- [ ] Do not publish real student marks, names, or identifiers.
- [ ] Share real reports only with authorized staff.
- [ ] Do not use AI to guess missing marks.
- [ ] Verify calculations before summarizing with AI.
- [ ] Review AI summaries for unsupported claims.
- [ ] Flag incomplete or invalid records for manual checking.
