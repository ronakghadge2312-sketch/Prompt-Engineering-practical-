# AI Summary Prompt

Copy the verified statistics from `reports/student_performance_report.md` into your approved AI tool and use this prompt:

> Act as an educational report-writing assistant. Summarize the supplied student performance statistics in a clear, neutral paragraph. Use only the figures and observations provided. Do not calculate or change marks, invent missing values, identify causes without evidence, or make unsupported judgments about individual students. Mention the strongest and lowest subject averages only if they are supplied. State that incomplete records are excluded from aggregate calculations and require manual checking. Keep the summary concise and suitable for a student practical report.

## Verification Rules
1. Calculate totals and percentages using formulas or code before asking AI to summarize.
2. Provide only verified figures to the AI.
3. Compare the AI summary with the report's calculations.
4. Correct any conflicting or unsupported statement.
5. Save a genuine screenshot of the prompt and result if screenshots are required.
