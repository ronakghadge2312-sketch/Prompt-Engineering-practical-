# Security and Privacy Checklist

- [ ] Use fictional sample data in GitHub.
- [ ] Do not commit a public link to a private response spreadsheet.
- [ ] Restrict the spreadsheet to the teacher / authorized reviewers.
- [ ] Collect only Name, Email, and Course for this exercise.
- [ ] Remove or anonymize real student data in screenshots.
- [ ] Review duplicate or incomplete entries before taking action.
- [ ] Confirm that the form is shared only with the intended audience.
- [ ] Do not put passwords, API keys, or access tokens in the repository.
