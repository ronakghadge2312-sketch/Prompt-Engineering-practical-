# Security and Privacy Checklist

- [ ] Use fictional names and details in public examples.
- [ ] Do not paste confidential student records into an AI tool without authorization.
- [ ] Do not include passwords, API keys, or email credentials in GitHub.
- [ ] Confirm the deadline and submission method with an authorized person.
- [ ] Review AI-generated content for invented facts before use.
- [ ] Keep human approval before any manual sending.
- [ ] Ensure this workflow does not send emails automatically.
