# Security and Privacy Checklist

- [ ] Use fictional messages for public GitHub examples.
- [ ] Remove customer names, email addresses, phone numbers, addresses, and order IDs before AI processing.
- [ ] Do not upload private customer data or chat transcripts to a public repository.
- [ ] Never commit API keys, passwords, or support platform credentials.
- [ ] Treat AI output as a suggestion, not a verified fact.
- [ ] Flag ambiguous or incorrect classifications for human review.
- [ ] Do not let this demonstration automatically contact customers or issue refunds.
